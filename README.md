# Документация проекта

Статическая страница с техническими заданиями для студентов по направлениям разработки.

В странице размещены:

- `2 курс`: web-приложение, дизайн и полезные источники.
- `3 курс / Разработка приложений`: Android-сервис поиска специалистов, мобильный мессенджер, финансовый помощник и видеоплатформа на React.
- `3 курс / Разработка игр`: темы танковой 3D-игры и симулятора машиниста на Unity.

Материалы можно открыть напрямую по ссылкам вида `index.html#course-2/web`, `index.html#course-3-apps/messenger` или `index.html#course-3-games/train`.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Структура

```text
.
|-- index.html
|-- README.md
|-- assets/
|   |-- css/styles.css
|   |-- images/
|   |   |-- mint-logo.gif
|   |   `-- mint-success.gif
|   `-- js/
|       |-- documentation-content.js
|       |-- course-3-content.js
|       `-- script.js
```

`assets/js/documentation-content.js` и `assets/js/course-3-content.js` содержат текст заданий напрямую. Страница не загружает отдельные TXT-файлы и открывается без локального сервера.
