# Документация проекта

Статическая страница технического задания для проекта платформы поиска строительных специалистов.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Структура

```text
.
|-- index.html
|-- README.md
|-- assets/
|   |-- css/styles.css
|   |-- images/
|   |   |-- mint-logo.gif
|   |   `-- mint-success.gif
|   `-- js/
|       |-- documentation-content.js
|       `-- script.js
`-- docs/
    `-- technical-specification.txt
```

`docs/technical-specification.txt` - исходный текст документации.

`assets/js/documentation-content.js` - встроенная копия текста, используемая страницей при открытии без локального сервера.
