Что должно быть в каждом проекте

  • Рабочий интерфейс и серверная часть.
  • База данных с продуманной структурой.
  • Регистрация, авторизация и роли пользователей.
  • Основные функции выбранной темы.
  • Обработка ошибок и проверка вводимых данных.
  • Адаптивный интерфейс.

Что сдаётся в конце практики

  • Ссылка на Git-репозиторий.
  • Работающий проект.
  • ER-диаграмма базы данных.
  • Описание API.
  • Инструкция по запуску.
  • Краткая демонстрация проекта.

Рекомендуемый стек

Frontend: React + TypeScript · Backend: Node.js + NestJS · БД: PostgreSQL · ORM: Prisma · Авторизация: JWT · API: REST · Реальное время: WebSocket (если требуется) · Развёртывание: Docker.

Можно использовать аналогичные технологии, если они согласованы с руководителем практики.
